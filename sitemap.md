# STUDENT-HUB Overview and Sitemap

## Project Overview

STUDENT-HUB is a static student portal website. The current project has one completed home page and several planned page files for common student services.

The site is organized into:

- `index.html` - Home page with welcome text and main navigation.
- `student HUB project/css/style.css` - Shared stylesheet for navigation links.
- `student HUB project/js/script.js` - Shared JavaScript file, currently empty.
- `student HUB project/Pages/` - Planned feature pages for dashboard, courses, assignments, attendance, profile, login, registration, results, and contact.
