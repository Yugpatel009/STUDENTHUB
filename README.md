# HTML Semester 3 Projects

This workspace contains HTML/CSS/JavaScript practice projects for Semester 3.

## Projects

### Student HUB Project

`student HUB project` is a Student Hub web portal with pages for:

- Home
- Login and registration
- Student dashboard
- Profile
- Attendance
- Assignments
- Courses
- Results
- Contact

Open `student HUB project/index.html` in a browser to start the project.

### Demo

`demo/table.html` contains a small HTML table demo.

## How To Run

1. Open this folder in a code editor.
2. Open the required `.html` file directly in a browser.
3. For the main project, start with `student HUB project/index.html`.
